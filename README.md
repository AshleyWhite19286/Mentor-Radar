# 导师雷达 · Mentor Radar

面向上海交通大学集成电路学院低年级本科生的科研导航智能体：从研究所认识领域，从近期论文理解老师，再结合个人基础规划入门路径。

当前已同步学院官网（[https://icisee.sjtu.edu.cn/jiaoshiml.html](https://icisee.sjtu.edu.cn/jiaoshiml.html)）教师目录的12个分类，共273位人员。全部人员保留官网职称、所属分类和个人页来源；当前已有94位人员的384篇近期论文通过官方代表作或作者身份与单位交叉核验，其中187篇带公开摘要。原有12位的解读继续保留；其余论文会在获得可用模型凭证后生成摘要解读。平台人员保留真实职称，不自动视为招生导师。

## 本机运行

需要 Node.js 22.13 或以上版本、npm。项目使用 Node 内置 SQLite，不需要安装数据库服务。已在 Node.js 25.9.0 上验证。

```bash
npm ci
npm run dev
```

打开 **http://127.0.0.1:3000**。预置资料、照片和摘要解读可以直接浏览，无需Key或联网。

生产运行：

```bash
npm run build
npm start
```

生产构建采用Webpack，输出到`.next-production`，与开发缓存分开。`npm start`仅绑定本机；公网演示使用`npm run start:public`，并配置允许的网站源地址。

## 免费部署到Render（演示版）

保留现有页面、SQLite和后台任务，无需先接入云数据库。完整操作见[Render部署指南](docs/Render部署指南.md)。

1. 将代码推送到自己的GitHub仓库（可以私有），不上传本机数据库和凭证。
2. 登录Render，选择 **New → Blueprint**，连接仓库。
3. Render会读取根目录的`render.yaml`；确认服务方案为 **Free**，点击部署。
4. 构建成功后打开Render提供的HTTPS地址，即可浏览现有页面；模型功能仍在页面“模型设置”中填写自己的Key。

Render的`RENDER_EXTERNAL_URL`会自动启用该域名的接口访问；使用自定义域名时，将`RADAR_PUBLIC_ORIGIN`设为该域名的完整HTTPS源地址。免费实例闲置后会休眠，休眠、重启或重新部署会清除本地新增内容；仓库中的预置数据会保留。此版本为共享演示，不提供账号或用户数据隔离。

## 连接学校模型

点击右上角“模型设置”，地址默认是`https://models.sjtu.edu.cn/api/v1`。填入你自己的Key，点击“获取模型”，选择实际可用的模型并测试连接。也可输入其他公开HTTPS的Chat Completions兼容接口。

Key只保留于当前页面内存，刷新后清除；后端只在发起请求及执行当前任务期间使用，不写入数据库、日志或预置数据。不要把自己的Key写入源码。学校接口的可达性及具体模型能力需要使用个人Key验证。

## 可以体验什么

- **导师名录**：姓名、方向及论文关键词搜索，按12个机构筛选。
- **研究所导览**：官方背景、通俗解释、当前样本的研究观察与入门基础。
- **教师详情**：论文信息／摘要关键词／通俗解读与入门三列，手机端按论文分区排列。
- **我的科研起点**：输入兴趣、课程、编程经验与可投入时间，得到最多3位推荐、论文依据和四周计划。
- **个性化匹配（New Match）**：独立入口 `/#new-match`，空白时随机展示16位教师；输入停止约1秒后，从全部导师中动态检索并精排最多16位。卡片显示个人查看次数和有效阅读时长，点击侧栏查看资料并按需生成四周入门计划。原 `/#match` 功能保持独立。
- **证据追问**：选择教师或论文继续提问，回答附已读取证据的链接。
- **补充导师**：读取公开个人页或粘贴资料，确认同名作者、逐篇确认论文，也可用DOI补充摘要。
- **简介修订**：新增资料后提出研究观察修改建议，展示前后差异；确认后才采用，可恢复旧版。
- **收录审阅**：查看选人依据、真实职称、论文与摘要覆盖、来源及导师资格状态。

## 数据与检索规则

先检查近24个月的独立论文，不足5篇再扩至36个月，最多展示最新5篇。预印本与正式版关联去重；年份或月份不能精确判定窗口边界时待核实。36个月仍不足则如实展示，不用旧代表作补足。

预置来源包括学院官网、机构建设介绍、公开个人主页、OpenAlex、Crossref和arXiv记录。运行时用OpenAlex发现作者与作品，Semantic Scholar作为作者检索备用，并按已知标题向arXiv补充摘要；用户可用DOI从Crossref补充论文。没有要求使用Google Scholar。

预置摘要解读由Codex根据已获得的摘要整理，标注为“基于公开摘要”。缺摘要条目不生成完整解读。当前没有收录经核验的个人体验反馈；不会从奖项、论文或传言推断导师风格。研究主题不等于正在招生的项目。

本机新增内容、任务、分析缓存及简介历史保存在`data/local.sqlite`。预置快照是`data/seed.json`，不会被用户添加覆盖。备份个人数据时先停止服务，再备份本机SQLite文件及关联的WAL文件；不要把本机数据库作为公开提交材料。

New Match 的个人浏览足迹保存在当前浏览器的 `localStorage`，支持清除；输入和随机批次保存在 `sessionStorage`，同一标签页返回或刷新可以恢复。详情打开、页面在前台且最近60秒有操作时累计阅读时长，关闭、切后台或闲置时暂停。浏览记录不参与推荐排序，也不上传服务端。动态匹配与入门计划使用独立请求，不写入旧匹配任务或数据库；模型Key仍只在内存中保留。

## 验证与数据维护

```bash
npm test
npm run typecheck
npm run data:audit
npm run test:ui
```

浏览器测试默认使用本机Google Chrome，无需登录态；若没有Chrome，可在Playwright配置中改用已安装的测试浏览器。测试会自动启动本机开发服务，并保存截图到`docs/screenshots`。

`npm test`包含模型返回模拟、数据规则、引用核验、导入、匹配、问答及简介采用／恢复等测试。**模拟测试通过不代表已经用真实学校Key完成联调。** 当前真实模型服务尚待个人Key验证。

研究数据采集脚本：`scripts/collect.py`抓取预选人员与照片；`scripts/discover.py`产生学术作者候选；`scripts/enrich.py`补充已选择论文的DOI、时间与摘要；`scripts/supplement.py`继续补充缺失摘要。候选须人工核对，不应直接把作者索引全量结果视为正确。

运行`npm run data:directory:all`可重新抓取官网目录的全部分页、个人页和照片，并合并到种子数据；`npm run data:directory:three`用于仅同步每类前三位。种子日期为2026-10-20；界面检索窗口随实际日期滚动。
