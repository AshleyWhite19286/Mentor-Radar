# 接口与实现说明

## 数据流

预置快照与用户本机记录合并为目录。姓名、职称、机构归属等事实保留官方来源；摘要、模型解读、匹配结果和简介修订分别存储，不覆盖官方事实。

实时模型请求通过本机服务发往设置中的HTTPS接口。Key只存在于浏览器内存及当前服务请求／任务闭包中；任务表、缓存和错误信息不保存凭证。模型缓存按证据、接口地址和模型标识复用，不以Key作为缓存内容。

任务状态写入SQLite：运行中、完成、失败。页面轮询任务进度。来源失败、限流、无摘要或模型格式不合规时明确提示，已存在的资料继续可读。后台并行任务上限为3；服务退出或任务过期后可重新发起。

## 主要接口

所有接口位于`/api/`。本机请求必须来自同源。实时分析请求携带`settings: {baseUrl, apiKey, model}`，但任务持久化时不包含settings。

|方法与路径|输入／作用|返回|
|---|---|---|
|GET catalog|合并预置与本机目录|institutes、mentors、revisions|
|GET tasks/:id|读取任务|status、steps、result或error|
|POST models|模型设置|models字符串列表|
|POST connection|模型设置|连接测试结果|
|POST match|student及模型设置|taskId；任务结果含推荐、四周路径及来源|
|POST new-match|profile（兴趣、年级、课程、编程、时间、目标、其他条件）及模型设置|summary、最多16项recommendations、limitations|
|POST new-match/plan|mentorId、profile及模型设置|适配解释、基础差距、首篇论文ID、首个任务、四周计划及引用|
|POST chat|question、可选mentorId／paperId|taskId；任务结果含回答、证据、缺口|
|POST explain|mentorId、paperId|taskId；更新本机论文解读|
|POST import/inspect|url或text、英文姓名|taskId；返回资料草稿和作者候选|
|POST import/papers|已完成的草稿任务ID、作者候选ID|taskId；返回按窗口筛选的论文|
|POST doi|doi、可选用户粘贴摘要|论文草稿及服务端保存的临时token|
|POST import/save|草稿任务ID、确认后的资料、勾选论文ID、手动token、confirmed:true|taskId；保存教师并尝试生成简介建议|
|POST revisions/propose|instituteId|taskId；修订建议或unchanged|
|POST revisions/action|建议id及accept／reject／restore|修改后的建议状态|

导入保存从服务端任务结果取论文，不直接信任客户端传入的完整论文对象。用户确认的是资料与归属，不能被前端默认为已确认。

## New Match 动态匹配

`/#new-match` 与原 `/#match` 使用不同组件和接口。空白输入时在浏览器中无放回随机抽取最多16位导师，同一会话保持批次稳定，可主动换一批。平台人员不纳入导师候选。所有画像字段初始为空，表示未知。

停止输入约1秒后自动请求；中文输入法组词期间暂停。第一轮模型读取全量导师的精简目录，理解需求、遵守明确条件并召回最多48位；第二轮读取候选方向、先修基础和最新3篇已收录论文的标题及可用摘要，按问题相关性、明确条件、基础及目标精排最多16位。允许少于16位或零结果。服务端按首次出现顺序对重复候选和推荐去重；不存在的教师ID、非本轮候选ID及跨教师引用会反馈给模型自动纠正一次，仍不合法则拒绝返回。每一条推荐（包括重复项）先核验教师及引用归属，再去重；不会将模型文本转换成新教师记录或猜测替换编号。

动态接口直接返回结果，不进入旧任务队列、不保存画像或模型输出。客户端最多缓存20组结果，仅存内存。输入变化会取消旧请求，迟到响应不能覆盖当前结果；调用方取消信号与现有45秒网络超时合并，单轮动态匹配总时限100秒。更新或失败时保留已有卡片，详情打开时冻结推荐。

浏览足迹按教师ID累计：主动打开详情计一次查看；仅详情打开、页面在前台、最近60秒内有用户操作的时段累计阅读。关闭、页面隐藏和卸载时结算，定期保存到本机浏览器，不上传也不影响排序。输入和随机批次存入当前标签页的会话存储；模型凭证不进入浏览器持久存储。

## 论文时间与去重

独立论文按DOI、arXiv标识、规范化标题合并，保留版本。正式版与预印本合并后以正式版时间参与窗口筛选；多条正式记录使用较早时间。Crossref明确提供在线发表日期时优先使用，缺失时保留索引日期及待复核说明。

先判断24个月是否至少5篇，再决定是否扩到36个月。日期只有年或月时按可能区间判断：跨越边界则列为待核实，不按虚构的1月1日纳入。所有窗口随实际日期滚动。

## 简介修订

机构保留官方背景与独立的近期研究观察。证据指纹未变化时不调用模型。新证据生成建议后，建议处于pending，旧简介保持有效。采用和恢复在SQLite事务中检查当前版本，过时建议不能覆盖更新内容。拒绝、采用、恢复均保留历史。

首版自动建议仅修改研究观察；官方背景由维护者依据独立官方材料整理。它不会因个人新论文自动被改写。

## 运行边界

公开网页读取限制协议、端口、大小、超时和重定向，并拒绝回环及常见内网地址。带模型凭证的请求不自动跨重定向发送。网页仅被视为证据，模型提示要求忽略资料中的指令；追问回答使用Markdown组件渲染标题、列表、加粗、代码块和表格，忽略原始HTML和图片，并过滤危险链接；不执行网页脚本。

学校模型专用请求精确放行`https://models.sjtu.edu.cn/api/v1/models`和`https://models.sjtu.edu.cn/api/v1/chat/completions`，支持校园网或代理DNS映射的内网地址，仍校验HTTPS证书并禁止重定向。此例外不用于公开网页抓取或其他自定义模型地址。

当前是单机原型，不提供账号隔离、公共发布或全学院自动导入。若未来部署公网，需要另行设计认证、用户数据隔离、任务队列、费用控制与网络边界。
